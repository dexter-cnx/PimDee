# PimDee - พิมพ์ดี

PimDee is a static-first Thai/English beginner touch-typing tutor focused on the Thai Kedmanee layout and English QWERTY.

## MVP

- Kedmanee + QWERTY keyboard visualization with finger zones
- 6 beginner lessons
- Natural and forced-correction typing modes
- Live WPM, accuracy, elapsed time and progress
- Keyboard mistake heatmap
- Custom text practice
- Thai physical-key mapping: users can keep an English keyboard layout active while PimDee maps `a -> ฟ`, `j -> ่`, etc.
- Local-first stats through `StatsAdapter`

## Run

```bash
npm install
npm run dev
```

## Build

npm run build
